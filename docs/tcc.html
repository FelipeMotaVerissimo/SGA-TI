Como rodar

Real — MySQL na sua máquina

npm install
npx prisma migrate dev
npx prisma db seed
npm run dev

Não é preciso nova migration: o model ServicoExecutado já existe no schema.

Preview — sem banco

npm install
node sandbox/preview.js 3000
node sandbox/testeE2E.js

Login admin / admin123. Dados em memória, recriados a cada boot.

Limitações do ambiente de preview

O preview troca apenas src/config/database.js por um Prisma falso em memória — todo o resto é o código real. Ele valida rotas, regras de negócio, validações, sessão, flash, views e regressão. Ele não valida SQL, migrations, tipos nativos do MySQL, constraints de unicidade, integridade referencial e o comportamento real de $transaction. Por isso o teste com MySQL na sua máquina continua obrigatório antes de homologar.
